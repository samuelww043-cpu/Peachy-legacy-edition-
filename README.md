# Peachy Legacy Edition

Peachy Legacy Edition is a version of Minecraft Legacy Edition that runs on less than 600 MB of RAM, which is up to around 60% less than the original 4JCraft build. It is easy to install and is already compiled when downloaded.

You’re allowed to do whatever you want with the code, but you can’t try to submit it to be officially picked up by 4JCraft or claim that Peachy Craft was coded by you. It was made by AI, so 4JCraft will not accept this version under its current rules, and neither should this be credited to anyone.

I do encourage you to either just have fun playing it or try to recode it by hand so that 4JCraft can accept the optimized version. That’s all I really expect from this.

Have fun.
